# Fitnes assistans

## Виртуальный помощник для спортсменов. Помогает в похудении или наборе мышечной массы.

## Что умеет:

### Кухня 

1) Расчет базового обмена веществ
2) Расчет необходимого потребления калорий для достижения цели. Составление плана.
3) Подсчет трат калорий за день, исходя из телосложения и активности в течение дня
4) Подсчет дефицита/профицита за день/неделю/месяц (Отслеживания прогресса на графиках)

### Тренировка
1) Какие есть упражнения и на какие группы мышц, гайд по выполнению (текст и видео)
2) Запись тренировок (Какие упражнения, количество подходов и повторений)

### Общение
1) Возможность выкладывать посты в ленту (комментарии, лайки)
