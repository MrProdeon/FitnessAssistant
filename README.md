# Users - приложение для пользователей

Созданы эндпоинты для CRUD операций с разграничением прав доступа.
Добавлена авторизация/аутентификация с помощью JWT-токена.
- Неавторизованный пользователь может только создать пользователя (пройти регистрацию).  
- Авторизованный пользователь может посмотреть список всех пользователей, детально просмотреть другого пользователя,
отредактировать или удалить только свой профиль.  
- Админ имеет полные права доступа: смотреть всех пользователей, удалять и редактировать любой профиль
